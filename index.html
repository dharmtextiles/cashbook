Card details

Default layout matches the sheet: A4 portrait, 6 mm left margin, no top margin. In the print dialog keep scale at 100% and turn off headers/footers.

Print position & spacing

Negative numbers move left/up. Label 1, 2 and 3 are the three slips on the page; the preview shows label spacing, the shifts and scale apply when printing.

Click a cell to edit; Meter, Days to Finish, Expected End Date and Sr No. are calculated. Pick loading dates from the calendar. Days to Finish comes from the Quality page, otherwise Meter ÷ 55.

Total beams to be empty 0

Quality

The same quality can be added again with different details. Entry date is always today. Ends and rate fill the Warping Card when you choose that quality there. Days to finish applies to beams of this quality loaded between the two dates, otherwise Meter ÷ 55 is used. Click a cell in the list to edit it later.

Drawing entry

Transfer Sr No. range

Rows in the range that have a Machine No. are grouped into one sheet per machine, with Sr No. in column P, like the macro. Rows without a machine are skipped.

Install on this device

Excel

Import reads the BeamProduction table from your workbook and replaces the current log. Export writes the same 16-column table.

Backup file

Saves everything (beam log, card, quality rules, print settings) in one .json file. Keep a copy in Drive or GitHub.

Cloud sync

Drive: offLocal only

Google Drive backup & sync

One-time setup in Google Cloud Console: create a project, enable the Google Drive API, set up the OAuth consent screen (add your own Google account as a test user), then create an OAuth client ID of type Web application. Put this app’s web address under Authorized JavaScript origins and paste the Client ID above. The app can only see the one file it creates, beam-data.json, in your My Drive. Use the same Client ID on every device.

GitHub sync

Use a private repository and a fine-grained token limited to that repository with Contents: read and write. The newest save wins when two devices edit at once.
